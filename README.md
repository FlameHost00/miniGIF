## 📖 Что такое miniGIF?

**miniGIF** – это десктопное приложение на базе Electron для хранения, организации и быстрого копирования GIF‑изображений по текстовым кодам (например, `:minipoka`).  

---

## ⚡ Быстрый старт

### Установка

1. Скачайте последнюю версию из раздела [Releases](https://github.com/ваш-репозиторий/releases) для вашей ОС (Windows, macOS, Linux).
2. Установите приложение стандартным способом.
3. Запустите miniGIF.

### Первое знакомство

После запуска вы увидите:

- **Боковую панель** со списком категорий
- **Основную область** с GIF‑карточками
- **Кнопку «GIF Панель»** в правом верхнем углу – это ваш быстрый доступ к коллекции из любого окна

---

## 🧭 Основной интерфейс

### Боковая панель (слева)

- **Список категорий** – клик по названию открывает её содержимое
- **⋮ (меню категории)** – редактирование / удаление (только для пользовательских категорий)
- **«Добавить GIF»** – добавить новый элемент в выбранную категорию
- **«Добавить Кат.»** – создать новую категорию
- **«Импорт»** – импортировать данные из ZIP или JSON
- **«Экспорт»** – экспортировать выбранные категории в ZIP
- **«Обновить Пр.»** – проверить обновления приложения
- **«Новые GIF»** – проверить наличие новых системных GIF (из репозитория)

### Основная область

- **Поиск** – работает только в системной категории 🔒 (ищет по коду GIF)
- **Карточка GIF** содержит:
  - **Код**
  - **Превью GIF**
  - Кнопки: **Копировать**, **Редактировать** (менять GIF), **Переместить** (в другую категорию), **Удалить**

## 🎯 Ключевые функции

### 1. Управление категориями

- **Создание:** нажмите **«Добавить Кат.»** → укажите название и выберите цвет на цветовом колесе.
- **Редактирование:** наведите на категорию → нажмите **⋮** → выберите **«Редактировать»**.
- **Удаление:** наведите на категорию → **⋮** → **«Удалить»**.  
  > ⚠️ При удалении категории все её GIF‑файлы удаляются **безвозвратно!**
- **Системная категория** 🔒 – защищена от изменений, содержит базовый набор GIF (обновляется через кнопку **«Новые GIF»**).

### 2. Добавление GIF

1. Выберите категорию (или создайте новую).
2. Нажмите **«Добавить GIF»**.
3. Введите:
   - **Код** – уникальный текст (например, `:minipoka`)
   - **URL** – прямая ссылка на GIF (поддерживаются `.gif`, `.mp4` конвертируются в GIF автоматически)
4. Нажмите **«Добавить»** – GIF загрузится и появится в категории.

> 💡 **Совет:** Если URL не указать, добавится только код – вы сможете отредактировать GIF позже.

### 3. GIF Панель (Floating Panel)

Нажмите **«GIF Панель»** в правом верхнем углу – откроется отдельное мини‑окно с вашей коллекцией.

- **Перетаскивание категорий** – меняйте порядок категорий (drag & drop).
- **Перетаскивание GIF** – меняйте порядок GIF внутри категории.
- **Закрепление поверх окон** – кнопка 📌 (панель всегда сверху).
- **Горячая клавиша** – по умолчанию `Ctrl+Shift+G` (можно изменить в настройках).

#### Быстрое копирование GIF

- **Одиночный клик** по GIF – код + пробел копируется в буфер.
- **Режим множественного копирования:**  
  Зажмите `Ctrl` (или `Cmd` на macOS) и кликайте по нужным GIF. При отпускании `Ctrl` все выбранные коды скопируются одной строкой через пробел.

### 4. Горячие клавиши и шорткаты

- **Глобальная горячая клавиша** – открывает/закрывает GIF Панель (по умолчанию `Ctrl+Shift+G`).
- **Шорткаты** – привяжите любой GIF к комбинации клавиш, чтобы копировать его мгновенно из любого приложения.

#### Как настроить шорткат

1. В GIF Панели или в главном окне нажмите кнопку **⚙️ с оранжевой шестерёнкой** (рядом с настройками горячей клавиши).
2. В открывшемся окне нажмите **«Добавить шорткат»**.
3. Кликните на любой GIF в коллекции – он будет выбран.
4. Нажмите желаемую комбинацию клавиш (например, `Ctrl+1`).
5. Нажмите **«Сохранить»**.

Теперь при нажатии этой комбинации код GIF скопируется в буфер (с пробелом в конце) и появится уведомление.

### 5. Импорт / Экспорт

#### Экспорт

1. Нажмите **«Экспорт»** на боковой панели.
2. Отметьте категории, которые хотите выгрузить.
3. Выберите место сохранения – будет создан ZIP‑архив с `data.json` и папкой `gifs/`.

#### Импорт

1. Нажмите **«Импорт»**.
2. Выберите ZIP‑архив или JSON‑файл.
3. Выберите стратегию:
   - **Объединить** – добавить новые данные к существующим (дубликаты по коду внутри категорий игнорируются)
   - **Заменить** – полностью перезаписать текущую коллекцию

> ⚠️ При импорте GIF‑файлы копируются во внутреннее хранилище приложения.

### 6. Обновление приложения

- Приложение **автоматически проверяет** наличие новых версий при старте.
- Вручную – нажмите **«Обновить Пр.»** на боковой панели.
- Если обновление доступно, откроется окно с описанием изменений.

### 7. Обновление контента (системных GIF)

- Нажмите **«Новые GIF»** – приложение проверит репозиторий на наличие новых GIF для системной категории.
- Если найдены новые GIF, появится уведомление с предложением обновить.
- Нажмите **«Обновить»** – все новые GIF загрузятся и добавятся в системную категорию.

## 🔧 Продвинутые возможности

### Редактирование GIF

1. Нажмите **«Редактировать»** на карточке GIF.
2. Измените код или URL.
3. Нажмите **«Сохранить»** – новый GIF загрузится, а старый файл будет заменён.

### Перемещение между категориями

- Нажмите **«Переместить»** → выберите целевую категорию из выпадающего списка.
- Элемент переместится (код и файл), исходная запись удалится.

> 🚫 **Ограничения:**
> - Нельзя перемещать элементы **из** системной категории.
> - Нельзя перемещать элементы **в** системную категорию.
> - Копирование разрешено **только из системной категории** (нажмите «Выбрать категорию» → копия создаётся в выбранной пользовательской категории).

### Поиск в системной категории

При переключении на системную категорию появляется строка поиска. Введите часть кода – GIF‑карточки отфильтруются в реальном времени.

## ❓ Часто задаваемые вопросы

<details>
<summary><strong>Где хранятся мои GIF?</strong></summary>

В папке `%APPDATA%/miniGIF/gifs` (Windows) или `~/Library/Application Support/miniGIF/gifs` (macOS).
</details>

<details>
<summary><strong>Можно ли использовать свои GIF без интернета?</strong></summary>

Да, все GIF хранятся локально после загрузки.
</details>

<details>
<summary><strong>Как изменить глобальную горячую клавишу для панели?</strong></summary>

Нажмите на кнопку с ⚙️ (синяя шестерёнка) в GIF Панели → **«Изменить горячую клавишу»** → нажмите нужную комбинацию → **«Сохранить»**.
</details>

<details>
<summary><strong>Почему не работают шорткаты?</strong></summary>

Убедитесь, что комбинация не занята другой программой. В некоторых ОС требуются дополнительные разрешения для глобальных хоткеев.
</details>

<details>
<summary><strong>Как удалить системную категорию?</strong></summary>

Нельзя – она защищена. Вы можете скрыть её, просто не переключаясь на неё, или удалить все её GIF через кнопку удаления (с подтверждением).
</details>
